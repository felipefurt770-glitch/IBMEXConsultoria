# IBMEX Consultoria — Landing Page

Pacote estático pronto para revisão e publicação.

## Estrutura
- `index.html` — landing page
- `styles.css` — layout, responsividade e identidade visual
- `script.js` — menu mobile, aviso de privacidade e ano automático
- `logo-ibmex.png` — logo aprovado
- `politica-de-privacidade.html` — política institucional inicial
- `sitemap.xml` — sitemap para mecanismos de busca
- `robots.txt` — regras básicas de rastreamento
- `conteudo-seo.csv` — inventário de conteúdo, contatos e SEO
- `PROMPT-CLAUDE-CODE.md` — instrução pronta para execução e deploy

## Antes de publicar
Substitua `SEU-DOMINIO.com.br` pelo domínio real em:
1. `index.html`
2. `sitemap.xml`
3. `robots.txt`

## Teste local
```bash
python -m http.server 8080
```
Depois abra `http://localhost:8080`.
